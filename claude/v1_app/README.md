# V1 Predictor — Web App (Proof of Concept)

Upload a video clip → predict V1 firing rates → visualize as a clickable
heatmap with per-electrode drill-down.

## What's in here

```
v1_app/
├── app.py                   Flask server (upload, jobs, JSON API)
├── inference.py             Model loading + streaming inference
├── precompute_baseline.py   One-time: extracts baseline rates & waveforms from .mat
├── best_v1_model.pt         Trained checkpoint (16 electrodes, 320x240 input)
├── ac1_u004_000.mat         Reference recording (provides baselines & waveforms)
├── lib/
│   ├── v1_encoder.py        Model architecture + .mat loader (unchanged from training)
│   └── video_to_frames.py   ffmpeg wrapper for frame extraction
├── templates/
│   ├── index.html           Upload page
│   └── results.html         Heatmap + drill-down page
├── static/
│   ├── styles.css           Lab-instrument theme
│   └── baseline.json        Generated by precompute_baseline.py
├── uploads/                 (created on first run; uploaded videos land here)
└── jobs/                    (created on first run; per-job working dirs)
```

## Requirements

System: `ffmpeg` on PATH.
Python: `flask`, `torch`, `numpy`, `scipy`, `pillow`.

```bash
pip install flask torch numpy scipy pillow
# Ubuntu/Debian:  sudo apt install ffmpeg
# macOS:          brew install ffmpeg
```

## First-time setup

```bash
cd v1_app
python3 precompute_baseline.py    # writes static/baseline.json (~30 KB)
```

This pulls per-electrode mean firing rates and mean spike waveforms from
the .mat file and bakes them into a static asset the frontend loads on
the results page. Re-run only if you swap in a different reference .mat.

## Running

```bash
python3 app.py
```

The server listens on `http://localhost:5000`. Open it in a browser,
upload a video (mp4/mov/avi/mkv/webm/m4v, ≤200 MB), and the results page
appears once processing finishes.

## What the app does

1. Receives the upload.
2. Calls `lib/video_to_frames.py` via subprocess to extract the first 30 s
   at 30 fps, scaled to 320×240 grayscale (the model's expected input).
3. Streams frames through the V1Predictor model in batches of 16.
4. Produces a (n_bins, 16) firing-rate matrix and serializes it to JSON.
5. Frontend renders the matrix as a Canvas heatmap. Clicking any row
   loads a drill-down: predicted PSTH over time (vs. baseline mean) plus
   the recorded mean spike waveform from ac1.

## Caveats

- **CPU inference is slow** (~5 min for a 30 s clip with the full 240×320
  CNN). On a CUDA GPU this drops to seconds.
- **Jobs are in-memory.** State doesn't survive a server restart. Fine for
  a POC; replace `JOBS` dict with Redis/SQLite for anything more.
- **Single model, single session.** Predictions reflect what the model
  learned about *these 16 electrodes from one penetration in one animal*,
  not V1 in general.
- **Frame rate must match the training rate.** If the model is retrained
  on different bin durations, change `FRAME_DURATION` in `lib/v1_encoder.py`
  and the `TARGET_FPS` constant in `app.py` in tandem.

## Swapping in a new model

The checkpoint determines `n_electrodes` and input `(H, W)` automatically;
`inference.py` reads them from the state dict. Drop in a new
`best_v1_model.pt` and rerun `precompute_baseline.py` with the matching
`.mat` file. Frame-extraction size is derived from the constants
`TARGET_W`/`TARGET_H` in `app.py` — keep these in sync with the model.

## First Usage
tar -xzf v1_app.tar.gz
cd v1_app/

# put your reference .mat file here (the one matching the checkpoint)
cp /path/to/ac1_u004_000.mat .

# install deps
pip install flask torch numpy scipy pillow
# plus ffmpeg via your system package manager

# precompute baselines (one-time)
python3 precompute_baseline.py

# run
python3 app.py
# open http://localhost:5000
